# Port the Cummins 3-layer calibration (input/calibration/02) from R to Python

Branch: `feature/python-cummins-3layer` (from `origin/main` at `299d073`).

## Goal

Replace `input/calibration/02_calibrate_cummins_3layer.r` with a Python
implementation that reproduces `EBM::FitKalman` (Cummins et al. 2020,
https://doi.org/10.1175/JCLI-D-19-0589.1; EBM v1.1.0), so the calibration no
longer depends on R, `FKF` and `EBM`. The R script stays until the port is
validated, then is retired in a separate change.

## What R does (source of truth: `EBM` v1.1.0 namespace)

1. Parameters are optimised in log space (`Transform`/`BackTransform`), 11
   parameters: gamma, C[1:3], kappa[1:3], epsilon, sigma_eta, sigma_xi, F_4xCO2.
2. `BuildMatrices`: continuous drift `A` (4x4, first state is the AR(1)
   forcing/noise state), `B = [gamma, 0, 0, 0]`, `Q = diag(sigma_eta^2,
   (sigma_xi/C1)^2, 0, 0)`; `Ad = expm(A)`, `Bd = A^-1 (Ad - I) B`, `Qd` by Van
   Loan (1978); stationary `Gamma0` from `vec(Gamma0) = (I - Ad (x) Ad)^-1
   vec(Qd)`; measurement matrix `Cd` maps state to (T1, N).
3. `KalmanFilter` (via `FKF::fkf`): `x0 = (F_4xCO2, 0, 0, 0)`, `a0 = Ad x0 + Bd
   F_4xCO2`, `P0 = Gamma0`, state intercept `dt = Bd F_4xCO2`, measurement
   noise `GGt = 1e-12 I`.
4. Objective: `-logLik + alpha * C3^2`, minimised with BOBYQA
   (`nloptr::bobyqa`, `xtol_rel = 1e-6`, `maxeval = 20000`).
5. Failure handling in `02`: up to 5 attempts, `alpha = 1e-5 * 10^attempt`;
   models that never converge are dropped. "Failure" is `iter == maxeval` or
   a negative nlopt return code.
6. Output CSV `4xCO2_cummins_ebm3_cmip6.csv` with columns model, run, conv,
   nit, gamma, C1-3, kappa1-3, epsilon, sigma_eta, sigma_xi, F_4xCO2
   (read by `03_convert-ebm3-to-impulse-response.py`).

## Design decisions

- **Own implementation of the likelihood, not `fair.EnergyBalanceModel`.**
  FaIR's EBM is a forward model. It has the same drift matrix and Van Loan
  step, but its forcing enters the temperature box, whereas Cummins' likelihood
  starts from `x0 = (F_4xCO2, 0...)` decaying with gamma, and the stationary
  covariance and measurement matrix are not there. `_eb_matrix` is private.
  We use FaIR's EBM as an independent cross-check in a test (same `A`, `Ad`),
  not as a dependency of the fit.
- **Optimiser: `nlopt` BOBYQA.** Same library `nloptr` wraps, so iteration
  paths should match R closely. `nlopt` is already in the pixi environment
  (transitive); make it an explicit dependency in `pixi.toml`.
- **Module:** `src/fair_calibrate/cummins_ebm.py` (library, testable);
  script `input/calibration/02_calibrate_cummins_3layer.py` (I/O and retry loop).
- The 2-layer model is out of scope.

## Validation

R is available in the pixi environment, so validation is direct:

1. Unit: for fixed parameters, `Ad`, `Bd`, `Qd`, `Gamma0`, `Cd` and the
   Kalman log-likelihood match R (`EBM:::BuildMatrices`, `KalmanNegLogLik`) to
   1e-8 relative. Reference values generated by an R script committed in
   `tests/`.
2. Unit: `A` and `Ad` match `fair.energy_balance_model.EnergyBalanceModel`.
3. Integration: on synthetic 150-year data simulated from known parameters
   (fixed seed), Python and R fits agree on the objective value; parameters
   are compared and any difference is reported, not hidden. Cummins'
   parameters are weakly identified in the long tail, so equal objective
   with different parameters is possible.
4. The real CMIP6 `4xCO2_cmip6.csv` is not in the working tree (needs
   `01_tabulate-4xCO2.py` and `data/cmip6-hbf`). Comparing on it is the
   final check and stays with the user.

## Status (2026-10-01): real CMIP6 data, 66 runs

Changes since the synthetic validation, each forced by what the real data showed:

- **`Qd` and `Gamma0` from the continuous Lyapunov equation**, not the Van Loan
  matrix exponential. At `gamma` of about 25 to 30 (R fits 12 of 65 runs there)
  scipy's `expm` returns an indefinite `Qd` (min eigenvalue about -1e8) and the
  filter returned -inf. R's `expm` copes; the Lyapunov route is stable in both
  and agrees with R to 1e-15 at normal `gamma`. Regression tests added using R's
  fit of FGOALS-f3-L r3 (`gamma` = 30) as the reference.
- **`gamma` is bounded at 10** (`GAMMA_MAX`, `fit_kalman(gamma_max=...)`). For
  the 12 "ridge" runs the exact likelihood has no finite optimum: on CAMS-CSM1-0
  `gamma` went 24 to 3,016 to 159,283 as the evaluation budget grew, while the
  likelihood kept improving. R stops at 24-30, apparently where its `expm`
  loses accuracy (inference; R's parameters evaluate 7 log-likelihood units
  worse than the unbounded optimum on CAMS). `ftol_rel` was tried and rejected:
  loose values stop normal fits early, tight values do not stop the ridge. A cap
  of 30 was tested against 10: 30 let BOBYQA stop early at `gamma` near 0 on
  five runs (log-likelihood 22-118 worse than R); 10 did not.
- **Two starting points per run**, keeping the better (second start must win by
  more than 0.1). BOBYQA from one start can stop early without complaint:
  FGOALS-f3-L r3 and r2 were 18.5 and 15.3 log-likelihood units better from the
  second start. `start_gap` is saved; NaN means only one start converged.
- Output gains `gamma_at_bound` and `start_gap` columns (appended, so script 03
  reads it unchanged).

Result against R (`WORKERS=8`, 389 s for 66 runs, nothing excluded):

- 49 of 53 non-ridge runs agree with R in every parameter to 1e-3 (median 1.4e-5).
  The impulse-response parameters from script 03 for these runs agree to 6.5e-5.
- No non-ridge run is worse than R by more than 0.1 log-likelihood units. Four
  differ (NorESM2-MM, MIROC-ES2L, FIO-ESM-2-0 r2, GFDL-CM4 r1): Python's fits are
  equal or better (up to 6 units), and the guard flagged all four (three converged
  from one start only, one had a start gap of 0.48). ECS differs from R by up to
  16% on these.
- 12 ridge runs: `gamma` 2.9 to 10 (9 on the bound). Log-likelihood against R's
  fits: median 1.6 worse, from 7.3 better to 20.5 worse; ECS up to 23% different.
  This is the price of the bound and is a choice, not an error.
- Python fits NorESM2-LM (one start only), which R excluded. 66 rows against 65.

### C3 >= C2 constraint and suspect flags (2026-10-01)

Requested because in the run above 5 fits had `C3` < `C2` (C3 between 0.001 and
1.3) and `epsilon` between 100 and 28,000. `fit_kalman(c3_min_ratio=1)` bounds
log(C3/C2) below by 0 (the optimiser works on log(C3/C2) in place of log(C3), so
BOBYQA enforces it exactly); `C3_MIN_RATIO` sets it for the script. `epsilon`
outside 0.5-2.5 is flagged as suspect, not bounded. Output gains `c3_at_bound`,
`suspect`, `suspect_reasons`.

Result (66 runs, 393 s, nothing excluded):

- 60 of 66 fits are unchanged from the unconstrained run (to 1e-3); the
  constraint is inactive for them. A test confirms an inactive constraint does
  not move the optimum.
- Epsilon above 100 is gone (max 3.78). Six fits changed. FGOALS-f3-L r3 went
  from `C3` 0.001 / `epsilon` 28,380 to `C3` 67.6 / `epsilon` 1.46 with a
  log-likelihood 19 units better, so the old fit was an optimiser failure.
- Four fits end on the constraint (`C3` = `C2`): NorESM2-LM, NorESM2-MM,
  GFDL-CM4 r1, FGOALS-f3-L r2. The data prefer a deepest layer no larger than
  the middle one. For NorESM2 the likelihood equals the old degenerate fit
  (within 0.01); for GFDL-CM4 and FGOALS r2 the bound costs 1.6 and 3.8 units.
  Three of the four have `epsilon` of 2.5 to 3.8.
- Low `epsilon` is not touched by the constraint: five fits are below 0.5
  (0.000 to 0.444), four of them with `C3` of 160-380 against `C2` of 9-23.
  FIO-ESM-2-0 r2 collapsed to `epsilon` of 0.000 and `gamma` of 0.018, with a
  log-likelihood 20.6 better than R's (R has `epsilon` 3.04 and `C3` < `C2`).
- 11 of 66 fits are suspect: 7 `epsilon` out of range, 4 on the C3/C2 bound,
  2 with disagreeing starts, 7 with only one start converged (reasons overlap).
- Against R: unchanged for the 49 matching non-ridge runs (IRM within 6.6e-5).
  Python is worse than R by more than 0.1 log-likelihood on one non-ridge run
  (GFDL-CM4 r1, 1.6 units, constraint bound); ECS differs by up to 34% on the
  differing runs. FaIR's stochastic step fails for 2 of 66.
- FaIR's `stochastic_run` raises "must be symmetric positive semidefinite" for
  2 of 66 Python fits and 1 of 65 R fits, at moderate `gamma` (R: NorESM2-MM,
  `gamma` 1.5). Not caused by the bound; not investigated.

## Two-layer model (2026-10-01)

Requested because the three-layer fits look over-parameterised for 150 years of
data. The module, `02_calibrate_cummins.py` (renamed from `..._3layer.py`; set
`N_LAYERS=2`) and `03_convert-ebm3-to-impulse-response.py` now take two or three
layers. `c3_min_ratio` / `c3_at_bound` / `C3_MIN_RATIO` became `deep_min_ratio` /
`deep_at_bound` / `DEEP_MIN_RATIO` (deepest layer over the one above: C3/C2 for
three layers, C2/C1 for two). Three-layer results are unchanged (matrices still
match R to 1e-10; script 03 output byte-identical).

Validated against R's own two-layer code (`EBM`, k = 2): matrices, likelihood and
a fit on the synthetic series (46 tests), and R's two-layer fit of all 66 CMIP6
runs with the same starting values as the old `calibrate_cummins_2layer.r`.

Results, 66 runs, 114 s on 7 workers (three layers: 393 s):

- Python against R, two layers: 65 of 66 within 1e-3 in every parameter (median
  1.4e-5); none differ in log-likelihood by more than 0.1. R's two-layer fits show
  no `gamma` runaway (none above 15), so the ridge is a three-layer problem.
- The two-layer fits needed none of the guards: no `gamma` at the bound, no
  deep/above ratio on its bound, `epsilon` 0.88 to 2.27, every run converged from
  both starts, FaIR's stochastic step works for all 66. One run is flagged
  (INM-CM4-8, starts differ by 53; the better fit was kept). Three layers: 11 of
  66 suspect, `epsilon` 0.00 to 3.78, 9 on the `gamma` bound, 6 single-start.
- In-sample fit favours three layers: unpenalised log-likelihood is a median 13.5
  units better (90th percentile 25, max 50); AIC prefers three layers in 59 of 66
  runs and BIC in 55 (BIC with n = 300 observations, 2 series x 150 years). This
  does not settle overfitting, since AIC is in-sample.
- The test most directly aimed at overfitting does not show it: coefficient of
  variation across members of the same model (8 models with two or more runs) is
  about the same, ECS 0.02 for both, `epsilon` 0.06 (two layers) against 0.04
  (three), `gamma` 0.14 against 0.16.
- ECS and TCR barely move: two-layer / three-layer median ratio 0.984 for ECS and
  0.992 for TCR; TCR within 2% for 5th to 95th percentile; ECS 5th to 95th
  percentile 0.94 to 1.24, max 1.64.
- Not migrated: the sampling and constraining scripts read the three-layer files
  only (list in the README notes).
